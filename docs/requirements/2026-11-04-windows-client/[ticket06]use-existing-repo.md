# 06 — 用已有的仓库做笔记本

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 用户从云端账号里已有的笔记本中选一个，或粘贴网址，下载到一个空文件夹。原有文件原样保留。下载过程不往那个笔记本里写进程序自己的文件。

**Blocked by:** 05 — 笔记本文件夹

**Status:** ready-for-agent

- [ ] 「用已有的」列出账号能访问的笔记本。这台程序建的排在前面，其余按最近更新排序。超过 6 个时可以搜索
- [ ] 每一项能看出是不是只有自己可见、多久前更新、属于哪个组织。已经添加过的不能再添加一次
- [ ] 点选后询问在这台电脑上叫什么，以及放在哪个文件夹。默认名称和默认位置与新建时一致，位置规则与 05 相同
- [ ] 下载前说明原有文件会原样保留。公开的、以及特别大的笔记本会额外提醒
- [ ] 可以粘贴浏览器里的网址来下载，带有具体文件夹的网址也会得到整个笔记本
- [ ] 导入不往笔记本里写文件，不改名称说明，沿用对方已有的默认分支
- [ ] 以 `.` 开头的文件夹默认不在文件树里显示，但会随同步走
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
