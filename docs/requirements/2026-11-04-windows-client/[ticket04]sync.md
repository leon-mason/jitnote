# 04 — 同步

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 用户点一次同步，这台电脑上的修改到达云端，云端没有冲突的新内容也回到这台电脑。同步用合并，从不强推。编辑、离开笔记、退出程序都不另记版本。别人正在处理这个笔记本时，同步不搅和对方的工作。上次同步中途崩溃后，下次同步能继续，本地内容不丢。

**Blocked by:** 03 — 新建笔记本并写笔记

**Status:** ready-for-agent

- [ ] 点同步后，本地改动到达云端。云端能快进合并的修改会回来
- [ ] 同步使用合并，不强推。期间被人抢先推送时会再试，最多 3 次
- [ ] 编辑笔记、离开笔记、退出程序都不产生新版本。版本只在同步时记下，说明是人话
- [ ] 有还没同步的修改时，用户能看出来。别的程序已经记下但还没上传的内容也算
- [ ] 别的程序正在处理这个笔记本时，同步不清理对方的状态，并提示稍后再同步
- [ ] 上次同步中途崩溃留下的未完成状态，下次同步能恢复并完成，本地内容不丢。没有这台程序自己留下的标记时，不把别人的未完成工作清掉
- [ ] 笔记本里已经有的提交者名字不被覆盖；还没有时才写上
- [ ] 删除笔记或文件夹前，先把涉及的文件记一版，使没同步过的内容以后还能找回
- [ ] Ctrl+R 执行同步。若这个快捷键被编辑器拦住，去掉快捷键，同步按钮保留
- [ ] 不改变 Android 和 Mac 已有的同步行为
- [ ] 上述行为在 Mac 上有与 Android、Mac 对应的自动测试，测试通过，并在 Mac 上打出可运行的 Windows 安装包
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
