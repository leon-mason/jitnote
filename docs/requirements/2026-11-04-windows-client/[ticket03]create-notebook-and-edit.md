# 03 — 新建笔记本并写笔记

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 连上云端账号后，用户在默认位置新建笔记本，在两栏窗口里用文件树打开笔记，编辑或预览。没改过的笔记打开再离开，文件保持原样。设置里可以选择显示隐藏文件，以及打开笔记时默认是编辑还是预览。

**Blocked by:** 02 — 连接云端账号

**Status:** ready-for-agent

- [ ] 新建笔记本落在用户主目录的 `Jitnote` 下。同名时自动加序号，已有内容的文件夹不动
- [ ] 窗口是两栏。文件树是唯一导航，能展开和收起文件夹，能打开笔记
- [ ] 能新建笔记和文件夹，都建在当前高亮的位置；能重命名
- [ ] 能在编辑和预览之间切换。预览不改文件。新建的笔记以编辑打开
- [ ] 没编辑过的笔记，打开再离开后，文件逐字节不变
- [ ] 设置里可以打开「显示隐藏文件」。以 `.` 开头的文件默认不显示。`.git` 始终不显示
- [ ] 设置里可以选择打开笔记时默认为编辑或预览。这个选择只在本机
- [ ] 快捷键：Ctrl+N 新建笔记，Ctrl+Shift+N 新建文件夹，Ctrl+E 切换编辑/预览，Ctrl+, 打开设置。光标在编辑器里时，Ctrl+E 仍然能切换
- [ ] 某个快捷键若被编辑器拦住、应用收不到，这一版去掉该快捷键，对应按钮保留。Ctrl+E 不在可去掉的范围内
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
