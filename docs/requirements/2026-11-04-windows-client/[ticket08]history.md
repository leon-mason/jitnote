# 08 — 历史版本

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 用户可以查看一篇笔记以往记下的版本，并恢复其中一版。恢复前，当前内容先被记下，之后还能找回。恢复出来的内容随下一次同步上传。

**Blocked by:** 04 — 同步

**Status:** ready-for-agent

- [ ] 从笔记上能打开历史版本，看到以往的内容和时间
- [ ] 能恢复选中的版本。恢复前先把当前内容记一版
- [ ] 恢复后能从历史版本里找回恢复前的内容
- [ ] 恢复出来的内容在下一次同步时到达云端，恢复这个动作本身不立刻上传
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
