# 07 — 冲突时选择以哪边为准

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 同步发现同一篇笔记的同一处两边都改过时，列出这些笔记，让用户看过两边内容后选择以这台电脑还是云端为准。选择之前，笔记本里的文件保持原样。取消后云端不变，下次同步再问。没选中的那一版留在历史版本里。

**Blocked by:** 04 — 同步

**Status:** ready-for-agent

- [ ] 同一处两边都改过时，同步列出这些笔记并询问。改的不是同一处时继续自动合并，不询问
- [ ] 一边删除、一边修改也询问，并写明是哪边删的
- [ ] 可以逐篇选择以这台电脑还是云端为准，也可以一次全选
- [ ] 选择前能看两边的内容
- [ ] 询问期间，笔记本文件夹里的文件不变
- [ ] 选择后，笔记内容与所选的一边一致，同步完成，没有强推。没选中的那一版能在历史版本里找到
- [ ] 取消后，云端没有变化，本地已记下的内容还在，下次同步再次询问
- [ ] 询问期间云端又有新的修改时，已经做过的选择按笔记保留，新出现的冲突再问一次
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 上述结果在 Mac 上有自动测试，测试通过，并在 Mac 上打出可运行的 Windows 安装包
