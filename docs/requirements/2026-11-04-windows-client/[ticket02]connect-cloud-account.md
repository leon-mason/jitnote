# 02 — 连接云端账号

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 用户粘贴云端账号的令牌并完成验证。关掉再打开，账号仍然连着。令牌只留在这台 Windows 电脑的当前用户凭据里，不随用户配置漫游。断开账号后，这台电脑上不再留着可用的令牌。

**Blocked by:** 01 — Windows 安装包和两栏窗口

**Status:** ready-for-agent

- [ ] 能连接当前 Mac 客户端已支持的云端账号，验证失败时能看懂原因
- [ ] 关闭再打开后，云端账号仍然连着
- [ ] 令牌存在当前 Windows 用户的凭据管理器里，只留在这台电脑上，不随用户配置漫游
- [ ] 笔记本文件夹里没有令牌，本机状态文件里也没有令牌明文
- [ ] 断开账号后，凭据管理器里不再留着可用的令牌
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
