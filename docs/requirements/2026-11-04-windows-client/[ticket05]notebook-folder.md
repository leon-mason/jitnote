# 05 — 笔记本文件夹

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 创建笔记本时，用户能看到默认位置，也能改成自己的空文件夹。创建后不能再改位置。之后可以打开这个文件夹、复制路径。移除笔记本时，默认位置下的文件夹会删除，自己选的文件夹原样留下，云端都不动。文件夹被移走或磁盘没插上时，笔记本还在列表里，用户可以重新检查、指回原来的文件夹，或重新下载到原位置。

**Blocked by:** 03 — 新建笔记本并写笔记

**Status:** ready-for-agent

- [ ] 创建时能看到默认位置，并能改成另一个文件夹。选择窗口里可以新建文件夹。选中的文件夹本身就是笔记本文件夹
- [ ] 非空文件夹、文件、或位于另一个笔记本里面的文件夹会被拒绝，并说明原因。只含 `desktop.ini` 或 `Thumbs.db` 的文件夹可以选择
- [ ] 选了 OneDrive、Dropbox、iCloud 等会自动同步的位置时给出警告，仍能继续
- [ ] 创建后界面上没有修改位置的入口
- [ ] 「打开文件夹」在文件资源管理器中打开笔记本文件夹。「复制路径」得到完整路径。管理笔记本里也能复制路径
- [ ] 移除默认位置下的笔记本时，本地文件夹被删除。移除用户自己选的文件夹时，文件夹和里面的文件都还在。确认框写明路径和会发生什么。两种情况都不动云端
- [ ] 文件夹被移走、删除或所在磁盘没插上时，笔记本留在列表里，窗口换成说明页，写明原来的位置
- [ ] 「重新检查」在文件夹回到原处后能继续使用。「重新选择文件夹」只接受云端地址相同、且没被别的笔记本占用的文件夹，里面没同步的修改原样保留
- [ ] 「重新下载到原位置」只在原位置不存在或为空时进行。上一级文件夹找不到时不在别的地方建出新文件夹。没同步的修改如果原文件夹找不回来，确认框里写明
- [ ] 文件夹不可用时，同步会说明找不到文件夹，不会建一个新的。除重新选择和重新下载外，没有改位置的入口
- [ ] 下载失败时，用户选的空文件夹保留，只清掉下载放进去的东西。程序自己建的文件夹则一起清掉
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
