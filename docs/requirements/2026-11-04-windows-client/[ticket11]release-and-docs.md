# 11 — 同一次发版和使用说明

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** Windows 安装包和 Android、Mac 使用同一个版本号，出现在同一次发布里。使用说明写清这是 Windows 11 的程序、如何安装、笔记本放在哪里、系统提示发布者不明时如何打开，以及更新时如何替换。已发出的旧版本不补 Windows 包。

**Blocked by:** 02 — 连接云端账号；03 — 新建笔记本并写笔记；04 — 同步；05 — 笔记本文件夹；06 — 用已有的仓库做笔记本；07 — 冲突时选择以哪边为准；08 — 历史版本；09 — 别的程序改了文件，图片只显示；10 — 检查更新

**Status:** ready-for-agent

- [ ] 同一次发布里有 Windows 11 x64 的自包含压缩包，版本号与同一版 Android、Mac 相同

- [ ] 中文和英文使用说明写上系统要求、如何安装、笔记本的默认位置、未签名时如何打开、更新时如何替换
