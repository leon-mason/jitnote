# 10 — 检查更新

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 程序自己检查有没有新版本。打开时每天最多查一次，用户也可以手动查。查询不携带令牌，不发送笔记内容。用户确认后才下载。下载完打开压缩包所在的位置，由用户退出正在运行的记特，再换上新版本。

**Blocked by:** 01 — Windows 安装包和两栏窗口

**Status:** ready-for-agent

- [ ] 打开程序时会检查更新，每天最多一次。没网或查不到时不提示
- [ ] 可以手动检查。这时会明确告诉用户结果
- [ ] 只看最新的正式版本。发现新版本时先说明版本号、更新内容和安装包大小，用户点了更新才下载
- [ ] 下载过程能看到进度，可以取消
- [ ] 下载完成后打开压缩包所在位置。程序不覆盖正在运行的文件
- [ ] 查询不携带令牌，也不发送笔记内容
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
