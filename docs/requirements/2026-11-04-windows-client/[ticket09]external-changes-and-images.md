# 09 — 别的程序改了文件，图片只显示

**Source:** [需求规格](<[spec]windows-client.md>)

**What to build:** 笔记本文件夹被别的程序改过之后，文件树和正在打开的笔记跟着变，不弹窗询问。最后写入的内容留在文件里。笔记里的图片能看，保存笔记时不改写图片的写法。

**Blocked by:** 04 — 同步

**Status:** ready-for-agent

- [ ] 别的程序新建、删除、重命名或修改文件后，文件树自动更新
- [ ] 正在打开的笔记被别的程序改了，编辑器直接显示新内容，不弹窗。没编辑过的笔记不会因此被写回
- [ ] 笔记被移走或删除后，不会因为编辑器里还有内容就把它写回来
- [ ] 以 `.` 开头的名字不引起刷新，除非开着「显示隐藏文件」。`.git` 里面的变化不监听
- [ ] 回到程序时会再看一次有没有还没同步的修改
- [ ] 笔记里常见的几种图片写法都能显示，包括相对这篇笔记的、相对整个笔记本的、以及按文件名查找的
- [ ] 点笔记里的图片，或点文件树里的图片，能看大图
- [ ] 保存笔记不改写图片引用。图片不会被解析到笔记本外面
- [ ] 界面不出现 Git、Markdown、仓库、提交、分支、push、merge
- [ ] 自动测试在 Mac 上通过，并在 Mac 上打出可运行的 Windows 安装包
