# 01 — 同步不破坏别人的 Git 状态

**Source:** [需求规格](<[spec]notebook-folder.md>)

**What to build:** App 像其他 Git 工具一样使用笔记本。AI 或终端正在操作这个仓库时，点同步不会清掉它们的工作；App 自己崩溃留下的状态仍能恢复。外部提交能原样推到云端。Mac 和 Android 一起改。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 外部工具正在进行未完成的合并时点同步：合并状态和未提交的改动都不受影响，App 提示稍后再同步
- [x] 存在 `index.lock` 时，App 不删除它，而是稍等重试；一直拿不到时提示稍后再同步
- [x] App 在同步中途崩溃后，下次同步能恢复并完成，本地内容不丢
- [x] 外部工具提交后，工作区干净，点同步：该提交原样到达云端，App 不额外生成提交
- [x] 同样的情况，云端也有新提交：App 合并后推送，不强推，不改写外部工具的提交
- [x] 本地已配置提交者身份时，同步不覆盖；没配时才写入
- [x] 以上行为在 Mac 和 Android 都有测试，两端测试都通过
- [x] 设计说明「其他约定」里的崩溃恢复规则已改写，对应内容已从「已定待实现」移走
