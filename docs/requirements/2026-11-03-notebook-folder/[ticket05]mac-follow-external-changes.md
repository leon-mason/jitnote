# 05 — Mac：感知外部变化

**Source:** [需求规格](<[spec]notebook-folder.md>)

**What to build:** AI 或其他工具改了笔记本文件夹后，Mac 不用手动刷新就能看到。文件就是唯一的事实：打开的笔记被外部改动时，编辑器跟随磁盘，不弹窗，最后写入的赢。Android 的文件夹没有其他程序能写，不需要这项改动。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 外部工具新建、删除、重命名文件后，文件树自动更新
- [ ] 外部工具改了正在打开的笔记后，编辑器不弹窗，显示磁盘上的新内容
- [ ] 重新加载后，用户继续编辑时不会用旧内容盖掉外部的改动
- [ ] 没有编辑过的笔记不会因为重新加载被写回，仍逐字节不变
- [ ] App 自己保存文件不会触发重新加载，不打断输入
- [ ] 外部工具删除或移走正在打开的笔记时，App 不闪退，也不把它写回来
- [ ] 同步进行中的文件变化不造成重复加载或覆盖
- [ ] `scripts/build-mac.sh --test` 和 `editor/` 的 `npm test` 通过；如果改了 `editor/`，打包产物一起提交
- [ ] 设计说明里对应的行为已写进正文，并从「已定待实现」移走
