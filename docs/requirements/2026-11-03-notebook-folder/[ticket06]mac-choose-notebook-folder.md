# 06 — Mac：选择笔记本文件夹，打开和复制路径

**Source:** [需求规格](<[spec]notebook-folder.md>)

**What to build:** 在 Mac 上创建或下载笔记本时，用户能看到默认路径，也能改成另一个空目录。创建后路径不可更改。在笔记本里可以打开这个文件夹、复制它的路径，例如设为 AI 的项目目录。删除笔记本时按路径来源决定是否删除文件夹。

删除规则放在这张单子里，是因为拆到后面的话，中间状态下删除笔记会删掉用户自己指定的文件夹。
