# 02 — 同步之外不再自动提交

**Source:** [需求规格](<[spec]notebook-folder.md>)

**What to build:** 提交和推送合并成一个同步动作。平时的编辑只保存到磁盘，用户点同步时才提交所有改动并推送。会让未提交内容永久丢失的操作，先把涉及的文件记一版。用户能一眼看到还有未同步的修改。Mac 和 Android 一起改。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 编辑笔记、离开笔记、切到后台、退出 App、重命名、打开历史版本，都不产生提交；内容已保存到磁盘
- [x] 点同步后，`.gitignore` 之外的所有改动被提交并到达云端
- [x] 删除一篇未同步的笔记后，能从历史版本找回删除前的内容；这次提交只包含被删除的内容，不混入其他文件
- [x] 恢复历史版本后，能找回恢复前的内容；这次提交只包含涉及的文件
- [x] 新建笔记本的首次提交保留
- [ ] 有未同步的修改时，界面上能一眼看到；包括外部工具已提交但还没推送的内容（已实现并编译通过，界面还没有在真机或模拟器上看过；Mac 回到 App 时重新检查）
- [x] 用户没改过的笔记，打开再离开仍逐字节不变
- [x] 以上行为在 Mac 和 Android 都有测试，两端测试都通过
- [x] 设计说明的同步规则、对照表和「其他约定」已更新，对应内容已从「已定待实现」移走
- [x] README.md 和 README.en.md 里“自动记录版本”的说法已更新
