# 设计说明

本文记录 Git 笔记本的产品原则和关键技术决定，供各个客户端（Android、以后的 iOS / 桌面）共同遵守。

- 日期：2026-10-30
- 前身：私有方案《GitNote V1》（Flutter + 服务端 + 微信登录 + 试用/买断）。本项目改为**完全开源、没有服务器**，因此账号、试用、买断、服务端数据模型都不再适用；“真 Git”“隐藏 Git 术语”“冲突不丢数据”等原则保留。

## 产品原则

1. **用户是不懂技术的普通人。** 界面不出现 Git、Markdown、仓库、提交、分支等词。对照：

   | 技术概念 | 界面说法 |
   | --- | --- |
   | 仓库 | 笔记本 |
   | 克隆 | 下载笔记本 |
   | 提交 | （自动保存，不出现） |
   | fetch / pull / push | 同步 |
   | 合并冲突 | 两个地方都改过，已保留较新的版本 |
   | 提交历史 | 历史版本 |
   | 访问令牌 / 远端账号 | 云端账号 |

2. **真 Git。** 每个笔记本是完整的 Git 工作副本，有真实的提交，电脑上的任何 Git 工具都能接着用。不走平台 REST API 逐文件同步（那样本地没有 `.git`）。REST 只用于验证令牌、建私有仓库、列出账号里的仓库。
3. **没有服务器。** 令牌只存在设备上，App 只连接用户自己的 Git 托管平台。
4. **不改动用户的东西。** 遵守仓库已有的 `.gitignore`；App 自己的元数据只放在 `.gitnote/`（随仓库同步）和 `.git/gitnotebook/`（仅本机）。

## 同步规则

一个「同步」按钮依次执行：

1. 把工作区所有改动提交成一个提交（提交说明是人话：`编辑：笔记名`、`新建：…`、`删除：…`、`重命名：a → b`、`更新 N 个文件：…`，正文附设备名）。
2. `fetch` 默认分支。
3. **merge**（不 rebase，不改写历史）。能快进就快进。
4. 有冲突时逐个文件处理：
   - 两边都改了：保留**最后修改时间较新**的一边（比较合并基点之后各自最后一次改动该文件的提交的作者时间），时间相同时保留云端。
   - 一边删除、一边修改：保留修改的那一边（不因删除丢内容）。
   - 被放弃的版本仍在历史里，并记录到 `.git/gitnotebook/conflicts.json`，界面提供「看看另一个」「换成另一个」「就用现在的」。
   - 合并提交说明：`同步：合并云端修改（N 个文件两边都改了，已采用较新版本）`。
5. `push`。被拒（期间别人推送了）就回到第 2 步，最多 3 次。**从不强推。**

其他约定：

- 编辑器离开笔记、App 切到后台时自动保存并提交；同步前再兜底提交一次。
- 同步进行时编辑器只显示“正在同步”，结束后重新加载文件，避免同步过程中写文件。
- 上次同步中途崩溃（仓库停在 MERGING 状态或残留 `index.lock`）时，下次同步先放弃未完成的合并再重来；本地改动在合并前已经提交，所以不会丢。
- 新建笔记本：在平台上建**私有**仓库（`auto_init`），仓库名由笔记本名转成英文，纯中文名用 `notes-xxxxxx`；仓库描述写 `[GitNotebook] 显示名`，用于在第二台设备上识别；`.gitnote/notebook.json` 记录显示名等信息。
- 删除笔记本只删除本机副本，不删除云端仓库。

## 编辑器

`editor/` 是一个独立网页，用 [Milkdown](https://milkdown.dev/) 的 Crepe 组件做所见即所得编辑，各客户端用 WebView 加载打包好的离线文件。

- 只启用笔记需要的功能：列表/待办、链接、图片、表格、选中文字后的浮动工具栏；不启用数学公式、代码高亮编辑器、AI、斜杠菜单（会和普通文字里的 `/` 冲突）。
- 自带底部中文工具栏：标题、加粗、列表、编号、待办、引用、撤销、重做。
- 保持文件稳定，减少无意义的差异：YAML 文件头原样保留；列表符号统一写成 `-`；只有用户真正编辑后才回写文件。
- 宿主接口（各平台一致）：
  - 宿主 → 编辑器：`window.GitNotebookEditor.load(markdown, { readonly, baseUrl })`、`window.GitNotebookEditor.getMarkdown()`
  - 编辑器 → 宿主：`window.GitNotebookHost.onReady()`、`window.GitNotebookHost.onChange(markdown)`（防抖，仅在真实编辑后）
- 相对路径图片通过 `baseUrl` 解析到笔记所在文件夹（Android 用 `WebViewAssetLoader` 把笔记本目录映射到 `https://appassets.androidplatform.net/notebook/`）。

## Android 技术选型

| 项目 | 选择 | 原因 |
| --- | --- | --- |
| 语言 / UI | Kotlin + Jetpack Compose（Material 3） | 原生体验、稳定 |
| Git | JGit 5.13 | 成熟的纯 Java 实现，无需原生库；5.13 是最后一个面向 Java 8 的版本，在 Android 上兼容性最好 |
| 令牌存储 | Android Keystore（AES-GCM） | 密钥不出设备；关闭系统备份 |
| 本地状态 | 一个 JSON 文件（账号、笔记本列表） | 数据量很小，不需要数据库 |
| 编辑器 | WebView + `editor/` | 与其他平台共用 |

JGit 被隔离在 App 自己的配置里（不读系统 git、不读 `~/.gitconfig`），见 `GitEnvironment.kt`。
